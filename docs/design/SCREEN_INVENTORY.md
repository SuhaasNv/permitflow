`OfficerCompareNavCollapsed` shows the collapsed 64 px navigation rail (hamburger in the top bar); every screen supports it.

Dialogs not drawn separately but specified: **Reject** (note required, danger primary), **Schedule site visit** (date optional, warning when addressed items unresolved), **Mark site visit done**, **Route to approval**, **Approve** (note optional), **Unsaved changes** (leave / stay), **Remove document** (draft only). All follow the S-22 dialog pattern: title as a question, consequence sentence in plain language, list of affected items, optional note, Cancel + one primary action.
