`OfficerCompareNavCollapsed` shows the collapsed 64 px navigation rail (hamburger in the top bar); every screen supports it.

Dialogs not drawn separately but specified: **Reject** (note required, danger primary), **Mark site visit scheduled** (date optional, warning when addressed items unresolved), **Mark site visit done**, **Route to approval**, **Return to review** (from Pending Approval back to Under Review), **Approve** (note optional, warning when check results are unresolved), **Unsaved changes** (leave / stay), **Remove document** (draft only). All follow the S-22 dialog pattern: title as a question, consequence sentence in plain language, list of affected items, optional note, Cancel + one primary action.
