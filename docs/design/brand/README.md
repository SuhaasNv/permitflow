# PermitFlow brand assets

| File | Use |
|------|-----|
| `permitflow-mark.svg` | App icon, favicon source, top bar mark (28 px) |
| `permitflow-mark-mono.svg` | Charcoal variant for print and monochrome contexts |
| `permitflow-logo.svg` | Horizontal lockup: mark + wordmark (requires Public Sans; falls back to the system sans) |

The mark is a form (three lines of decreasing length, a sectioned application) whose last line is completed by a check: a permit that has been verified. Geometry: 32 px grid, 7 px corner radius, 2.6 px round strokes. Colours: primary `#A8192A` on white; the glyph is always white. Minimum size 20 px. Clear space: half the mark's width on every side.

Do not recolour the glyph, add gradients or shadows, or place the mark on photographs. The wordmark is Public Sans 700 with -0.01 em tracking, always charcoal `#1B2430`, never red.
