# 05 Planning

How the three days were run. The Notion board ("PermitFlow, Xtremax Assessment") was the live board during the work; this folder is its mirror in the repository plus the rules the board ran under. Written 17 Sep 2026 and updated at every sprint close.

| Document | What it holds |
|----------|---------------|
| `USER_STORIES.md` | Every story US-000 to US-077, one to one with the board: same ids, titles, priority, sprint day and acceptance criteria; the branch names in the git history carry these ids |
| `SPRINTS.md` | The three one-day sprints (goals, planned stories), the sprint definition of done, the close ritual, the cut order; the board as it stood after the release |
| `DELIVERY_PLAN.md` | The day-by-day plan as planned and as executed, risks and how they were handled |
| `KANBAN.md` | The flow rules: columns, WIP limit, mid-day check, story-to-day mapping |
| `DEFINITION_OF_DONE.md` | The story-level definition of done: functional, tests, security, documentation, board |
| `notion/` | Screenshots of the board after v0.3.0: the workspace page, the Epics table, the Stories table |

Where the outcome of each sprint is written: `../../CHANGELOG.md` (Shipped, Slipped, Retro per sprint) and `../../SCOPE.md` (the scope re-read at each close).
